## 3. Inherited RF-P03 Rules

RF-P05 strictly inherits all principles frozen in RF-P03:
1. `death fact != automatic abort of everything`: An entity reaching 0 troops does not unconditionally terminate outer execution scopes.
2. `already committed work != pending work`: Already committed damage and troop mutations are never rolled back.
3. `transaction-local ownership != outer Action ownership`: The interrupt or continuation decided by RF-P05 belongs solely to the local damage partition micro-transaction. It does not dictate outer Action cancellation, ReactionChain aborts, or BattleFinalization timing.
4. `victory condition satisfied != BattleFinalized`: Any victory marker generated by commander death is recorded as an input for RF-P04, not prematurely arbitrated by RF-P05.

## 4. Share Predicate

The Share lethal target extractor enforces the strict 12-point predicate:
1. DAMAGE_SHARE operational on protected target;
2. Theoretical share amount $D_{\text{sharer\_theoretical}} > 0$;
3. Sharer alive prior to transaction;
4. Sharer `currentTroops > 0`;
5. Source / Share instance valid;
6. $D_{\text{target}}$ is lethal to protected target ($\text{target.currentTroops} \le D_{\text{target}}$);
7. Target reaches 0 troops from this $D_{\text{target}}$ commit;
8. No Share replacement occurred;
9. No source suppression active;
10. No upstream Evasion / Resistance cancellation;
11. Event window extends far enough to observe subsequent actions or transaction completion;
12. Target and sharer identities unambiguous.

Future test suites must enforce the following regression specifications:

### SHARE
- `SHARE_01_NON_LETHAL`: Target survives $D_{\text{target}}$ -> target commits, then sharer commits $D_{\text{sharer}}$.
- `SHARE_02_TARGET_LETHAL`: Target reaches 0 troops from $D_{\text{target}}$ -> `TARGET_DEATH_INTERRUPT` triggers; pending $D_{\text{sharer}}$ dropped; sharer suffers 0 troop loss.
- `SHARE_03_SHARER_OVERFLOW`: Sharer currentTroops $< D_{\text{sharer}}$ -> `min()` troop loss; overflow discarded without repartition or target return.
