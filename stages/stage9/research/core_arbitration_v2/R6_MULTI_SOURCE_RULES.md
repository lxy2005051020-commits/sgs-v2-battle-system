- **`cfg: 24` 覆盖效果**: **0 例**。

### 2. 结论审慎化与等级核定 (BF-07)
- **观察事实 (OBSERVED)**: 在全部 1,550 例可观察样本中，重复施加同类控制均触发了 cfg 23 免疫拒绝，未见持续时间刷新或新状态覆盖。
- **通用证据局限与未知项 (UNKNOWN, TAUNT 除外)**: 
  由于 cfg 23 日志明确提示“已存在同等或更强”，而战报事件中无法直接标定控制效果的内部权重（强度等级），对于尚未开展专项交叉矩阵研究的其他控制状态，**仍无充分战报数据证实“更强控制是否能够覆盖已存在的较弱同类控制”**。
- **TAUNT 专项覆盖结论 (RESOLVED)**:
  `TAUNT / 嘲讽` 已在后续专项研究中完成跨来源、跨持续时间与跨战法类型审计。所有现有嘲讽均共享同一优先级，已有 `TauntInstance` 时后续嘲讽一律拒绝注册，不刷新、不覆盖。`[X]身上已存在同等或更强的「嘲讽」效果` 对 TAUNT 仅是通用冲突文案，不能据此推导隐藏强度等级。
- **裁决结论**:
  对除 TAUNT 外、尚未专项封口的控制状态，继续维持 **Grade B (STRONG，附带强覆盖未知说明)**；严禁把该通用未知项反向覆盖 TAUNT 已完成的专项结论。

## 二、 多反击与多群攻的多来源处理

### 1. 多反击战法触发实证 (EM-24)
检索同一武将同时装备多个被动反击战法（如甘宁同时装备【气凌三军】与【后发制人】）的受击样本：
- **全库有效切片**: **仅 8 例**。
- **触发表现**: 受击后按武将战法装配栏位顺序（第二战法格 $\rightarrow$ 第三战法格）各自独立判定并连续输出反击伤害。
- **评级核定**: 由于有效样本仅 8 例，评级由 A 诚实降为 **Grade C (PROVISIONAL)**。

### 2. 多群攻战法触发
- 武将同时具备多种群攻来源时，按战法栏位顺序先后判定并独立执行溅射。

## 三、 增益与持续伤害状态的多来源表现

与控制状态不同，属性增益与持续伤害状态（灼烧、沙暴、水攻、中毒、溃逃）呈现以下规则：
1. **同来源同技能刷新**:
   - 检出 **7,875 例 `cfg: 25`**（`[X]身上的「灼烧」效果已刷新`）。同技能再次命中时，刷新持续回合数。[Grade A]
2. **异来源独立并存**:
   - 不同武将或不同战法施加的同名持续伤害（如陆逊的灼烧与周瑜的灼烧），在受击者身上作为独立 State 实例并存，各自独立计时与结算扣血。[Grade A]
