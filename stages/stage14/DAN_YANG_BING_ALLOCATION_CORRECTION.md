# 丹阳兵生成分配修正

日期：2026-10-12。用户在解释2000兵刃伤害生成临时兵时明确纠正：“这个2000是在场武将平均分配，然后采取的进一法”。此规则覆盖PR #63采用的全队共享池及生成向下取整选择。

```text
D = 上一回合我军全体兵刃实际伤害
N = 本回合开始时我军仍存活的武将人数
每名存活武将新获得 = ceil(D * 1.0 / N)
本人更新后池量 = floor(本人旧池量 * 0.9) + 新获得
本人受谋略伤害抵挡 = min(本人池量, floor(本人分配伤害 * 36%或40%))
```

2000伤害、3人在场：每人667，合计2001；2人在场：每人1000；1人在场：2000。进一法按每人获得量执行，不把余数强行塞回到原始总量。已阵亡武将不获得新临时兵。上一回合已造成伤害的武将，即使随后阵亡，其已发生伤害仍计入全队上一回合总量。

临时兵池状态现在施加于全队各人，受到谋略伤害时只扣受击者本人的池；某人的池耗尽不能借用队友池。每个人独立叠加、衰减和移除。丹阳兵携带副将阵亡后，存活队友的状态仍按原提供者DEATH-E规则保留。

此次仅修改生成分配及池归属。生成比例1.0、平均分配与进一法为用户指定；衰减先于生成、衰减/抵挡向下取整、实际扣兵统计口径和分担/分配之后抵挡仍保留待战报验证边界。

验证：丹阳兵专项23项，既有合并对抗审计9项，共32项通过；全量2224 passed；D1冻结owner哈希及11项对抗测试通过。实际测试包含三人/两人/一人在场、1点伤害分给3人各1临时兵、2000/3向上取667、本人池耗尽不借用队友、正式EffectExecutor、许可重放、携带者阵亡和每个兵池分别账本守恒。
