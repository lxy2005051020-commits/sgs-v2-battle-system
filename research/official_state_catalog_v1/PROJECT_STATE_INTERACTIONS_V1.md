## 先攻 + 遇袭

项目确认规则：

```text
先攻 = +1
普通 = 0
遇袭 = -1

先攻 + 遇袭
= +1 + (-1)
= 0
= 普通行动层
```

因此，同一武将同时拥有 `first_strike`（先攻）和 `ambush`（遇袭）时：

1. 两个行动优先级修正相互抵消。
2. 该武将进入普通行动层，不抛出未解析交互异常。
3. 在普通行动层内继续按有效速度从高到低排序。
4. 只有与其他普通层单位同时满足有效速度相同，才由 `RandomSystem.shuffle()` 裁决先后。

## 证据边界

当前官方接口词条分别明确“先攻使武将优先行动”和“遇袭使武将延后行动”，但没有在词条原文中直接说明两者同时存在时的结算。

上述“相互抵消归零”是**项目补充确认规则**，不得反向改写或伪装成 `Global.LangId` 官方词条原文。
